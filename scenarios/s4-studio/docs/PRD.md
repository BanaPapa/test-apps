# PRD · 4. 카드 스튜디오

## 한 줄 요약

동네와 달을 고르면 인스타그램·스레드에 바로 올릴 **카드 이미지 3장과 본문 후보 3가지**를 만들어 주는 앱. 카드의 숫자는 앱이 계산하고, 카드 제목과 본문은 분석 모델이 쓴다. 과장 표현과 지어낸 숫자는 자동으로 걸러낸다.

## 누가, 언제 쓰나

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| SNS 를 하는 중개사무소 | 매달 동네 실거래 소식을 올린다 | 디자인 고민 없이 3장 + 글 |
| 부동산 콘텐츠를 만드는 개인 | 여러 동네 소식을 빠르게 만든다 | 동네만 바꾸면 같은 틀로 |
| 분양·마케팅 담당 | 사업지 주변 시세를 가볍게 알린다 | 출처가 박힌, 숫자가 정확한 카드 |

## 이 앱이 하는 일

1. 동네·기준 달(기본 지난달)·계정 이름(@)·카드 비율(1:1 / 4:5)을 고른다.
2. 앱이 카드 숫자를 계산한다: 이달 거래 수, 3.3㎡당 중위가와 1년 흐름, 이달 가장 비싼 거래 2건.
3. 분석 모델이 **카드 1 제목**(세 줄)과 **본문 3가지 어조**(숫자 위주 / 동네 이야기체 / 질문형)를 쓴다.
4. 본문마다 금지어(편집 가능)와 자료에 없는 숫자를 검사해 표시한다.
5. 카드 3장 미리보기(실제 내보낼 그림과 같은 그리기 함수로 그린다), 본문 하나 고르기.
6. **이미지 3장 받기**(PNG, 1080 폭) · **본문 복사**(고른 본문 + 해시태그 + 출처).

## 하지 않는 것

- SNS 에 직접 올리기(계정 연동)
- 사진·지도 넣기
- 카드 디자인 자유 편집(색 테마 4가지 중 고르기만)
- 서버 저장
