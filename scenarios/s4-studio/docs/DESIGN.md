# DESIGN · 4. 카드 스튜디오

목표 화면: `design/mockup.html`, 그림: `design/preview.png`. mockup 의 숫자·본문은 예시다.

## 1. 인상

**포스터 작업실.** 거의 흰 바탕에 검정 글, 카드는 형광 연두와 검정으로 크게. 카드 글꼴은 굵은 포스터체(Black Han Sans), 화면 글꼴은 본고딕. 모든 누르는 것은 알약 모양. 화면 자체는 조용하고, 카드만 시끄럽다.

## 3. 글꼴

```
https://fonts.googleapis.com/css2?family=Black+Han+Sans&family=Noto+Sans+KR:wght@400;500;700;900&display=swap
```

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--font-poster` | `'Black Han Sans', sans-serif` | 앱 이름, 카드 안 큰 글 |

크기(px): 앱 이름 25 · 영역 제목 20/900 · 본문 15 줄높이 1.7 · 라벨 13.

## 4. 배치

```
[도구줄] padding 18 40, 아래 1px --line
  카드 스튜디오(poster 25) | 지역 select 알약 | 기준 달 알약 | 인증키 알약(라벨+입력) | 비율 1:1|4:5 알약 | 오른쪽 끝 "예시 데이터"
[본문] padding 32 40 48, 두 덩어리 간격 40
  왼쪽(나머지 폭)
    카드 3장 가로 줄 (각 폭 272, 간격 20, 넘치면 가로 스크롤)
    "모델이 쓴 본문, 하나를 고르세요" 20/900 + 오른쪽 [다시 쓰기] 테두리 알약
    본문 후보 3개 (세로로, 라디오 + 어조 라벨 + 본문 + 글자 수)
  오른쪽(300~340)
    검은 판: 글쓰기 모델 + 연결됨 꼬리표 / 제공사 / API 키 / 모델 / 연결 확인
    모델이 쓰지 않을 말: 칩들 + 입력
    계정 이름 / 해시태그 / 카드 색(원형 견본 4개, 44px)
    [이미지 3장 받기] (--ink 바탕, --lime 글씨, 높이 52)
    [본문 복사] (테두리, 높이 44) + 글자 수
```

## 5. 부품

**도구줄 알약**: 높이 40, 1px `--field-line`, `--r-pill`, 흰 바탕. 인증키 알약은 안에 `--soft` 바탕 작은 입력(폭 120, 높이 30)을 품는다.

**비율 토글**: 알약 하나 안에 두 칸, 고른 칸은 `--ink` 바탕 흰 글씨.

**본문 후보**: `<label>` 전체가 누르는 영역. 2px 테두리(`--line`, 고르면 `--ink`), 고르면 바탕 `--lime-tint`. 위에 어조 13/700 `--muted`, 검사 꼬리표(금지어·숫자) 13 `--danger`. 본문 15 `white-space: pre-line`.

**검은 판**: `--panel`, `--r-card`, padding 22. 입력칸 `--panel-field` + 1px `--panel-line` + `--r-field`(10). 연결됨 꼬리표 = `--lime` 바탕 `--ink` 글씨 13/700.

**금지어 칩**: 높이 32, `--chip`, 글 13 취소선, 오른쪽 × 버튼(`aria-label="{말} 빼기"`).

**카드 색 견본**: 44px 원 4개, 고른 것 3px `--ink` 테두리, `aria-label` 테마 이름(연두, 검정, 흰색, 주황).

**카드 미리보기**: FSD F5 의 canvas 를 폭 272 로 줄인 것, `--r-card`. 받는 중에는 같은 크기 `--soft` 사각형.

## 6. 상태 화면

| 상태 | 보여줄 것 |
|---|---|
| 처음(키 없음) | 카드 자리에 `--soft` 사각형 3개, 가운데 "동네와 달을 고르면 카드 3장을 만듭니다" + 예시 데이터 버튼 |
| 모델 미연결 | 카드 1 은 fallbackHeadline, 본문 후보 자리에 "모델을 연결하면 본문 세 가지를 써 드립니다" |
| 쓰는 중 | 후보 3칸 뼈대, 다시 쓰기 버튼 "쓰는 중…" |
| 0건 | 카드 자리에 "이달 신고된 거래가 없습니다" + 기준 달 바꾸기 안내 |

## 7. 좁은 화면 (< 768px)

- 도구줄 알약들이 줄 바꿈. padding 16.
- 카드 줄은 가로 스크롤(scroll-snap), 카드 폭 240.
- 오른쪽 덩어리가 아래로. 이미지 받기 버튼은 화면 아래에 붙지 않는다(일반 흐름).
