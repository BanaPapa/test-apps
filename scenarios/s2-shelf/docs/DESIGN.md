# DESIGN · 2. 단지 서랍

목표 화면: `design/mockup.html`, 그림: `design/preview.png`. mockup 의 단지명·숫자는 지어낸 예시다.

## 1. 인상

은회색 바탕 위에 **기계로 깎은 듯한 흰 카드**들이 서랍처럼 놓여 있다. 카드는 두 겹 테두리(바깥 반투명 쟁반 + 안쪽 흰 판)로 만든다. 굵은 고딕 제목, 숫자는 고정폭. 강조색은 **코발트 파랑 하나**. 크고 둥근 모서리와 알약 버튼.

밝은 화면만 만든다.

## 5. 부품

**쟁반 카드(두 겹)**: 바깥 div = `--tray` 바탕 + 1px `--tray-line` + padding 6 + `--r-tray`. 안쪽 div = `--surface` + `--r-card` + `--shadow` + `inset 0 1px 0 rgba(255,255,255,.9)` + padding 28px 30px.

**강조 카드**: 서랍 두 번째 단지. 안쪽 판 바탕 `--accent`, 글씨 `--on-accent`, 보조 글씨 `--on-accent-2`, 가는 선 흰색, 별 버튼 바탕 `rgba(255,255,255,.16)`.

**별 버튼**: 44×44 원, `--accent-tint` 바탕, `--accent` 별(★). 담기 전 칩에서는 ☆ `--muted`.

**알약 꼬리표**("1년 최고가"): 13px 700 `--accent` 글씨, `--accent-tint` 바탕, padding 4px 10px.

**칩**(다른 단지): 높이 44, 1px `--line`, 흰 바탕, ☆ + 이름 15px + 건수 13px 고정폭 `--muted`.

**점 그림·가격 폭**: FSD F3 그대로. 축 숫자 13px 고정폭 `--muted`, 바닥 축선 1px `--ink`.

**움직임**: 카드가 대표로 올라올 때 0.4s `cubic-bezier(.32,.72,0,1)` 로 opacity·transform 만. `prefers-reduced-motion: reduce` 면 움직이지 않는다. 버튼 누를 때 `scale(.98)`.
