# PRD · 2. 단지 서랍

## 한 줄 요약

동네 전체가 아니라 **내가 별표한 단지들의 거래만** 서랍처럼 모아 보는 앱. 단지마다 거래 한 건 한 건을 점으로, 평형별 가격 폭을 막대로 보여 준다.

## 누가, 언제 쓰나

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 갈아타기를 고민하는 1주택자 | 우리 단지와 옮기고 싶은 단지 두세 곳을 늘 비교한다 | 동 평균이 아니라 그 단지의 실제 거래 |
| 단지 전문 중개사 | 담당 단지 몇 곳의 최근 거래를 손님에게 바로 보여 줘야 한다 | 단지별 최근가, 최고가, 평형별 폭 |
| 청약·매수 대기자 | 눈여겨본 단지가 언제 얼마에 거래되는지 | 별표만 하면 계속 모아 보이는 곳 |

## 이 앱이 하는 일

1. 시도 → 시군구 → 동을 고르면 그 동에서 기간 안에 거래가 있었던 **단지 목록**이 뜬다(거래 많은 순).
2. 단지 옆 ☆ 을 누르면 **서랍**에 들어간다(최대 12곳, 이 브라우저에 저장). 다른 동·다른 구의 단지도 담을 수 있다.
3. 서랍 첫 단지는 크게(대표 카드):
   - 최근 거래가, 면적·층·날짜, "기간 최고가" 표시
   - 거래 점 그림: 가로 = 날짜, 세로 = 금액. 주력 평형은 파란 점, 나머지는 회색, 해제는 빈 점선 원
   - 평형별 가격 폭: 최저~최고 띠와 최근 거래 점
4. 나머지 단지는 작은 카드: 최근 가격, 가는 선, 한 줄 해설(규칙으로 만든다).
5. 아래 띠에 같은 동의 **아직 담지 않은 단지**를 늘어놓아 바로 담을 수 있게 한다.
6. 카드를 누르면 그 단지가 대표 카드로 올라온다.

분석 모델(AI)은 쓰지 않는다.

## 하지 않는 것

- 단지 기본 정보(세대수, 주차, 학군 등): 국토부 실거래 API 에 없다. 건축년도만 쓴다
- 시세 예측, 매수 추천
- 알림 (6번 시나리오의 몫)
- 서버 저장, 로그인

## 화면

`design/mockup.html` 참고. 자세한 것은 `docs/DESIGN.md`.

```
[떠 있는 상단 알약] 단지 서랍 | 단지·동 검색 | 인증키
[제목] 즐겨찾기한 단지 N곳 + 한 줄
[서랍] 대표 카드(넓게, 2칸 높이) | 작은 카드 | 작은 카드
       (더 있으면 아래 줄로 작은 카드 2열)
[띠]   이 동의 다른 단지 ☆ 칩들 (가로 스크롤)
```

## 완료 기준

- [ ] 예시 데이터로 강남구 · 대치동을 고르면 거래가 있었던 단지 목록이 거래 많은 순으로 뜬다
- [ ] ☆ 을 누르면 서랍에 들어가고, 새로고침해도 남아 있다. ★ 을 다시 누르면 빠진다
- [ ] 대표 카드에 최근 거래가, 거래 점 그림, 평형별 가격 폭이 보인다
- [ ] 점 그림에서 해제 거래는 빈 점선 원, 주력 평형은 강조색이다
- [ ] 작은 카드를 누르면 대표 카드가 그 단지로 바뀐다
- [ ] 다른 시군구 단지를 담으면 그 시군구도 받아 온다(시군구마다 한 번만)
- [ ] 같은 이름 다른 지번의 단지가 따로 나온다
- [ ] 서랍이 비어 있을 때 안내와 "동 고르기"로 이끄는 화면이 있다
- [ ] 가로 390px 에서 카드들이 한 줄로 쌓인다
- [ ] `npm test`, `npm run build` 통과
