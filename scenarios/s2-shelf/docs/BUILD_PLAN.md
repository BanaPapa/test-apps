# BUILD_PLAN · 2. 단지 서랍

단계마다 **확인**을 통과해야 다음 단계로 간다.

## 0단계. 준비

- `npm install` → `npm test` 통과 확인. `.env.example` 을 `.env.local` 로 복사.

## 1단계. 토큰과 뼈대

- DESIGN 2·3절 → `app/globals.css`, `app/layout.tsx`(`<title>` "단지 서랍").
- `components/TopPill.tsx`(상단 알약: 이름, 검색, 동 고르기 버튼, 인증키 묶음), `components/Tray.tsx`(두 겹 카드 껍데기, children 을 받는다).
- 빈 서랍 화면(FSD F7)을 먼저 그린다.

확인: http://localhost:3000 에서 빈 서랍 화면이 mockup 의 색·모서리로 보인다.

## 2단계. 계산 함수와 테스트 (화면보다 먼저)

- `lib/shelf.ts`: `complexKey`, `listComplexes`, `featuredCard`, `sideCard` + areaGroup·주력 평형 도우미.
- `tests/shelf.test.ts`: FSD 마지막 절.

확인: `npm test` 통과.

## 3단계. 동 고르기, 받기, 즐겨찾기 저장

- `components/DongPicker.tsx`(F1 판), 진행 띠, 세션 캐시(F5).
- "이 동의 단지" 띠(F6)와 즐겨찾기 저장(F2). 칩 ☆ 를 누르면 서랍 목록(아직 단순 이름 목록이어도 됨)에 들어간다.
- 예시 데이터 버튼: 강남구 대치동을 열고 거래 많은 두 단지를 담는다(F7).

확인: 예시 데이터 버튼 → 진행 띠 → "이 동의 단지" 띠에 대치동 단지 칩들이 거래 많은 순으로 보이고, 두 단지가 서랍 목록에 담긴다. 새로고침해도 남는다.

## 4단계. 서랍 카드

- 대표 카드(F3: 점 그림·가격 폭은 `components/DealDots.tsx`, `AreaRanges.tsx`), 작은 카드(F4, 버튼 중첩 금지 구조), 카드 누르면 대표로.

확인: 칩 ☆ 로 세 단지를 담고 새로고침 → 그대로 남아 있다. 작은 카드를 누르면 대표가 바뀌고, 별을 누르면 대표가 바뀌지 않고 서랍에서만 빠진다. 해제 거래가 빈 점선 원으로 보인다.

## 5단계. 여러 시군구

- 다른 구(예: 키 모드에서 서초구)의 단지를 담았을 때 그 구를 따로 받아 오는지. 예시 모드에서는 동 고르기 판이 강남구로 고정되는지.

확인: 진행 띠에 "시군구 1 / 2" 가 보이고, 실패한 시군구 카드에만 오류가 뜬다(인증키를 일부러 틀려 확인).

## 6단계. 다듬기

- mockup 과 나란히 놓고 간격·크기·색 맞춤. 좁은 화면(DESIGN 7절). 움직임과 reduced-motion.
