# PRD · 5. 아침 보고

## 한 줄 요약

지켜보는 동네들에 **지난 확인 이후 새로 확인된 아파트 거래**를 매일 아침 8시 슬랙으로 보내 주는 앱. 숫자 목록은 앱이 만들고, 맨 위 요약 두 문장은 분석 모델이 쓴다. 웹 화면에서는 설정, 미리보기, 지난 보고 기록을 본다.

## 누가, 언제 쓰나

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 중개사무소 팀 | 아침 회의 전에 우리 동네 새 거래를 공유한다 | 팀 채널에 매일 같은 시각 자동으로 |
| 동네 시장을 꾸준히 보는 투자자 | 매일 사이트를 뒤지기 싫다 | 새로 나온 것만, 요약과 함께 |
| 개발사업·분양 담당 | 사업지 주변 거래를 놓치지 않아야 한다 | 해제 신고까지 포함 |

## 이 앱이 하는 일

1. **매일 실행(자동)**: GitHub Actions 가 08:00 에 `scripts/daily.ts` 를 돌린다.
   - 지켜보는 동(최대 5곳)의 최근 12개월을 받는다.
   - 지난 확인 때 저장한 목록과 비교해 **새로 확인된 거래**와 **새 해제**를 찾는다. 국토부 API 에 신고일이 없어서 이렇게 하며, 그래서 "어제 신고"라고 단정하지 않는다.
   - 새 거래가 있으면 분석 모델이 요약 제목 한 줄과 두 문장을 쓰고, 앱이 거래 목록(금액 높은 순, 1년 최고가 표시)을 붙여 슬랙으로 보낸다.
   - 모델 문장에 자료에 없는 숫자가 있으면 요약을 빼고 숫자 목록만 보낸다.
   - 새 거래가 없으면 "새로 확인된 거래가 없습니다" 한 줄(끌 수 있음).
   - 해제는 받은 12개월 전체에서 찾는다. 그보다 오래된 계약의 해제는 잡지 못한다.
2. **웹 화면**:
   - 왼쪽: 최근 7일 보고 기록
   - 가운데: 고른 날의 메시지 미리보기 + "계약일과 확인일 사이" 그림(왜 오늘 온 거래가 한참 전 계약인지 보여 줌)
   - 오른쪽: 연결 세 가지(인증키·분석 모델·슬랙), 지켜보는 동, 설정 파일 만들기, 미리보기, 지금 한 번 보내보기

## 하지 않는 것

- 단지별 조건 알림(6번 시나리오의 몫)
- 이메일·카카오톡 발송
- 화면에서 GitHub 에 직접 쓰기, 서버 데이터베이스

## 화면

`design/mockup.html` 참고. 어두운 운영 화면, 호박색 강조.

## 연결

| 무엇 | 필요 | 어디에 |
|---|---|---|
| 공공데이터포털 인증키 | 필요 | 화면(미리보기용) + Secret `MOLIT_API_KEY` |
| 분석 모델 | 필요(없으면 요약 없이 목록만 보냄) | 화면(미리보기용) + Secrets `LLM_PROVIDER`, `LLM_MODEL`, `LLM_API_KEY` |
| 슬랙 Webhook | 필요 | 화면(시험용) + Secret `SLACK_WEBHOOK_URL` |
| GitHub 저장소 | 필요 | `docs/AUTOMATION.md` |

## 완료 기준

- [ ] 예시 데이터로 "미리보기"를 누르면 강남구 두 동의 최근 7일 계약분으로 만든 메시지가 가운데에 그려진다
- [ ] 모델을 연결하면 미리보기 맨 위에 요약 제목과 두 문장이 붙는다. 연결 전에는 규칙 제목("새로 확인된 거래 n건")만
- [ ] "지금 한 번 보내보기"가 슬랙에 같은 메시지를 보낸다
- [ ] "설정 파일 만들기"가 `config/report.json` 내용과 넣어야 할 Secret 이름 목록을 보여 준다(키 값은 보여 주지 않는다)
- [ ] `npm run daily` 를 두 번: 첫 번째는 기준선 메시지, 두 번째는 "새로 확인된 거래가 없습니다"(또는 sendWhenEmpty=false 면 무발송)
- [ ] 지켜보는 동을 하나 더한 뒤 실행하면 그 동은 기준선만 만들고 과거 거래를 쏟아내지 않는다
- [ ] 모델 문장에 자료 밖 숫자가 있으면 요약을 빼고 보낸다(테스트로 확인)
- [ ] 받기나 슬랙 보내기에 실패하면 스냅샷을 저장하지 않고 실패 기록을 남긴다(다음 실행이 같은 거래를 다시 보낸다)
- [ ] `state/report-history.json` 이 있으면 화면 왼쪽에 최근 7일이 보이고, 고르면 그날 메시지가 가운데에 그려진다
- [ ] GitHub Actions 에서 수동 실행이 성공하고 `state/` 가 커밋된다
- [ ] `npm test`, `npm run build` 통과
