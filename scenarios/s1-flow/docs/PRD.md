# PRD · 1. 동네 흐름

## 한 줄 요약

동네 하나를 고르면 **최근 1년 아파트 시세가 오르는지 내리는지**를 결론 한 문장과 차트 세 개로 보여주는 앱.

## 누가, 언제 쓰나

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 내 집 마련을 고민하는 실수요자 | 관심 동네가 요즘 어떤지 궁금하다 | 숫자 표가 아니라 "올랐다/내렸다/제자리"를 먼저 |
| 중개사무소 실장 | 손님에게 동네 흐름을 설명해야 한다 | 화면 하나 띄워 놓고 말할 수 있는 근거 |
| 부동산 공부하는 사람 | 여러 동네를 빠르게 비교해 보고 싶다 | 지역만 바꾸면 바로 같은 형식으로 |

## 이 앱이 하는 일

1. 시도 → 시군구 → 법정동(또는 "전체")과 기간(6개월 / 1년 / 3년)을 고른다.
2. 국토부 실거래가를 달별로 받아 **결론 문장**을 맨 위에 쓴다. 예: "신사동 아파트, 1년 새 3.3㎡당 8.6% 올랐습니다"
3. **3.3㎡당 중위 가격 차트**: 달별 선. 최고점과 마지막 값에 설명을 붙인다.
4. **월별 거래량 차트**: 막대. 최근 3개월을 진하게.
5. **면적대별 작은 차트 4개**: 60㎡ 이하 / 60~85 / 85~135 / 135 초과. 각각 최근 값과 변화율. 거래가 적으면 "표본 부족".
6. 거래 목록 표(접어 둠)와 엑셀(CSV) 받기.

분석 모델(AI)은 쓰지 않는다. 결론 문장은 정해진 규칙으로 만든다(FSD F3).

## 하지 않는 것

- 전세·월세, 오피스텔, 분양권 (아파트 매매만)
- 지도, 단지별 상세 (2번 시나리오의 몫)
- 여러 동네를 한 화면에서 겹쳐 비교
- 로그인, 서버 저장

## 화면

화면 하나. `design/mockup.html` 을 브라우저로 열면 목표 모습이 보인다. 자세한 것은 `docs/DESIGN.md`.

```
[머리줄] 동네 흐름 | 지역 고르기 | 기간 | 인증키
[결론]   큰 문장 + 기간·건수 한 줄
[차트]   3.3㎡당 중위 가격 (넓게)
[차트]   월별 거래량            [작은 차트] 면적대별 4개
[바닥줄] 표로 보기 · 엑셀로 받기 · 출처
```

## 완료 기준

- [ ] 예시 데이터로 강남구 · 신사동 · 1년을 고르면 결론 문장, 차트 3종, 면적대 4칸이 모두 그려진다
- [ ] 동을 "전체"로 바꾸면 강남구 전체로 다시 계산된다(다시 받지 않는다)
- [ ] 기간을 바꾸면 그 기간만큼 다시 받는다. 받는 동안 `n / N개월` 진행 표시와 중지 버튼
- [ ] 거래가 3건 미만인 달은 차트에서 빈 점·점선으로, 면적대는 "표본 부족"으로 보인다
- [ ] 해제 거래는 통계에서 빠지고, 표에서는 흐리게 + 취소선으로 남는다
- [ ] 인증키를 넣으면 다른 지역도 조회된다. 틀린 키는 "키 오류" 상태와 안내가 뜬다
- [ ] 표로 보기를 펴면 거래 목록이 계약일 최신순으로 나오고, 머리글로 정렬된다
- [ ] 엑셀로 받기를 누르면 한글이 깨지지 않는 CSV 가 내려받아진다
- [ ] 가로 390px 화면에서 가로 스크롤 없이 위아래로 쌓인다(표 상자만 가로 스크롤)
