# DESIGN · 1. 동네 흐름

목표 화면: `design/mockup.html` (브라우저로 열기), 그림: `design/preview.png`.
**mockup 의 숫자는 지어낸 예시다.** 모양·간격·색만 따라 하고 숫자는 실제 계산값을 쓴다.

## 1. 인상

신문 경제면의 데이터 그래픽. 흰 종이에 검은 글, 강조색은 **주황빛 빨강 하나**. 장식 없이 결론 문장과 차트가 화면을 이끈다. 차트 위에 설명을 직접 적는다(범례 상자 대신).

밝은 화면만 만든다(다크 모드 없음, 의도된 결정).

## 3. 글꼴

`app/layout.tsx` 의 `<head>` 에 Google Fonts 링크 하나:

```
https://fonts.googleapis.com/css2?family=Hahmlet:wght@600;700&family=IBM+Plex+Sans+KR:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500&display=swap
```

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--font-display` | `'Hahmlet', serif` | 결론 문장, 왼쪽 위 이름 |
| `--font-body` | `'IBM Plex Sans KR', sans-serif` | 그 밖의 모든 글 |
| `--font-num` | `'IBM Plex Mono', monospace` | 축 숫자, 거래량 숫자, 작은 차트 값, 인증키 입력 |

크기(px): 결론 40 / 이름 20 / 소제목·버튼 15 / 본문 15 / 라벨·축 13. 결론은 `letter-spacing: -0.01em; line-height: 1.25`.

## 4. 배치 (데스크톱 1280 기준)

```
┌ 머리줄 (padding 18px 56px, 아래 1px --line) ────────────────────────────┐
│ 동네 흐름   [지역: 시도][시군구][동]   [기간: 6개월|1년|3년]      [인증키 칸] 저장됨 │
└──────────────────────────────────────────────────────────────────────┘
본문: max-width 1180, 가운데, padding 40px 56px 56px, 12열 그리드, 열 간격 32, 행 간격 36

[12열] 결론 문장(최대 880px) + 아래 한 줄 sub
[12열] 3.3㎡당 중위 가격 차트, 높이 320
[7열]  월별 거래량           [5열] 면적대별 2×2
[12열] 바닥줄: "거래 n건 표로 보기"(링크) · [엑셀로 받기](테두리 버튼) · 오른쪽 끝 "출처 국토교통부 실거래가"
       그 아래로 표가 펼쳐진다
```

- 머리줄의 각 입력 묶음은 위에 13px 라벨, 아래에 높이 36px 컨트롤.
- 기간은 세그먼트 버튼(테두리 하나로 묶인 3칸). 선택된 칸만 `--ink` 바탕 + `--bg` 글씨.
- 결론 문장의 변화율 숫자만 `--accent`(오름) 또는 `--down`(내림) 색. flat·unknown 은 강조 없음.
- 차트 제목은 `figcaption` 15px 600 + 단위 괄호는 400 `--muted`.

## 5. 부품

**인증키 칸**: 라벨 "공공데이터포털 인증키" 13px, 입력 폭 200 · 높이 36 · `--font-num` 13px, 오른쪽에 상태 글자(13px): 저장됨·연결 확인됨 = `--ok`, 키 오류 = `--danger`.

**조회 버튼**: 머리줄 기간 오른쪽. 높이 36, `--accent` 바탕, 흰 글씨 15px 600. 화면에서 유일한 채움 버튼.

**진행 표시**: 조회 버튼 자리에 `n / N개월` (`--font-num`) + 폭 120 높이 4 막대(`--accent`) + "중지" 글자 버튼.

**가격 차트**: 4절과 FSD F4. 눈금선 `--grid`, 바닥 축선 `--ink` 1px, 설명 글 13~15px `--ink`, 최고점은 지름 12 꽉 찬 점.

**거래량 차트**: 높이 140, 막대 폭 70%, 위 모서리 3px. 최근 3개월 `--ink`, 나머지 `--bar-muted`. 숫자 13px `--font-num`.

**면적대 칸**: 위에 1px `--ink` 선, 이름 13px `--ink-2`, 선 차트 높이 44, 값 17px `--font-num` 500, 변화율 13px 600(오름 `--up`, 내림 `--down`, 표본 부족 `--muted`).

**표**: 머리글 13px `--muted`, 행 15px, 행 사이 1px `--line`, 숫자 열 오른쪽 정렬. hover 행 바탕 `rgba(22,24,29,0.03)`.

**툴팁**: `--ink` 바탕, `--bg` 글씨 13px, 모서리 `--radius`, 그림자 없음.

## 7. 좁은 화면 (< 768px)

- 머리줄: 묶음들이 줄 바꿈되어 쌓인다. 인증키 묶음은 맨 아래 전체 폭.
- 본문 padding 24px 16px. 그리드 1열: 결론 → 가격 차트(높이 240) → 거래량 → 면적대(2×2 유지) → 바닥줄.
- 결론 글꼴 28px.
- 표는 가로 스크롤 상자 안. 계약일·단지명 열 고정.

## 8. 하지 말 것

- 카드 그림자, 그라데이션, 둥근 큰 카드. 구역은 선과 여백으로만 나눈다.
- 범례 상자. 설명은 차트 위에 직접.
- 거래량과 가격을 한 차트에 축 두 개로 겹치기.
- 강조색을 두 가지 이상 쓰기(내림 파랑은 변화율 숫자에만).
- 숫자 가운데 정렬.
