# DESIGN · 3. 브리핑 데스크

목표 화면: `design/mockup.html`, 그림: `design/preview.png`. mockup 의 숫자·모델 id 는 예시다.

## 1. 인상

**어두운 책상 위에 놓인 인쇄 문서 한 장.** 화면의 주인공은 종이이고, 왼쪽(설정)과 오른쪽(모델 연결)은 책상 위 도구다. 문서 제목은 명조(출판물이라는 성격에 맞춘 의도된 선택), 나머지는 본고딕. 강조색은 **초록 하나**: 책상에서는 밝은 초록, 종이에서는 짙은 초록.

## 5. 부품

**제공사 버튼**: 2×2 격자, 높이 44, `--r-box`, 1px `--field-line`, 글 15. 선택 = 테두리 `--accent`, 바탕 `--accent-soft`, 굵게. `aria-pressed`.

**상태 상자**: `--desk` 바탕, 1px `--accent-line`(연결됨) 또는 `--field-line`, `--r-box`, padding 12 14. 왼쪽 상태 글(15/700 `--accent-text`), 오른쪽 "응답 1.4초 · 입력 1,240 토큰"(13 `--muted`).

**종이 문서**: FSD F6 순서. 머리 아래 2px `--paper-ink` 선. 판단 묶음: 왼쪽 3px `--paper-accent` 선, padding-left 16, 라벨 13/700 `--paper-accent`. 표 머리 아래 1px `--paper-ink`, 기준 달 열 굵게. 바닥 위 1px `--paper-line`.

**숫자 밑줄**: verified = `border-bottom: 1px dotted var(--paper-accent)`. unknown = `text-decoration: underline wavy var(--unknown) 1.5px; text-underline-offset: 3px`.

**경고 띠**: 종이 위, 폭 = 종이 폭, `#3A2020` 바탕, `--danger` 글 15, 오른쪽 "다시 쓰기" 글자 버튼. 인쇄 때 숨김.

**쓰는 중 뼈대**: 판단 묶음 자리 `--paper-line` 색 막대 3개(높이 14, 폭 100/92/70%), 1.2초 주기로 opacity 0.5↔1 (reduced-motion 이면 정지).

## 6. 상태 화면

| 상태 | 보여줄 것 |
|---|---|
| 키 없음, 처음 | 종이에 큰 제목 자리 "동네를 고르면 이번 달 브리핑을 만듭니다" + 예시 데이터 버튼 |
| 데이터 받는 중 | 종이 전체 뼈대 + 왼쪽 인증키 아래 `n / 12개월` |
| 모델 미연결 | 종이는 숫자 부분까지 채움, 판단 자리 안내 문구, 오른쪽 판 상태 `연결 안 됨` |
| 모델 오류 | 상태 상자에 `--danger` 메시지, 판단 자리는 이전 결과 유지 |

## 7. 좁은 화면 (< 768px)

세 덩어리가 세로로: 설정 → 문서(종이 padding 28 20, 제목 25) → 모델 판. 구분선은 위쪽 1px 로 바뀐다.

## 8. 인쇄

`@media print` 에서 책상·판은 사라지고 종이만 흰 바탕 A4 에. 글자색 그대로, 점선 밑줄 유지, 물결 밑줄 유지(고치지 않고 인쇄하면 보이도록).
