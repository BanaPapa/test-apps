# PRD · 3. 브리핑 데스크

## 한 줄 요약

우리 동네와 달을 고르면 **한 장짜리 시장 브리핑 문서**를 만들어 주는 앱. 숫자는 앱이 계산하고, 판단 문장은 연결한 분석 모델이 쓰며, 문장 속 숫자는 원자료와 자동으로 대조한다. 인쇄하거나 PDF 로 저장해 손님에게 건넨다.

## 누가, 언제 쓰나

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 중개사무소 대표 | 매달 초 손님·집주인에게 동네 시장을 설명한다 | 사무소 이름이 박힌 깔끔한 한 장 |
| 상담 직원 | 상담 전에 이 동네가 요즘 어떤지 30초 안에 정리해야 한다 | 결론 먼저, 근거 숫자는 정확하게 |
| 블로그·카페 운영자 | 월간 시장 글을 쓴다 | 숫자 틀릴 걱정 없는 초안 |

## 이 앱이 하는 일

1. 동네(시도·시군구·동)와 기준 달(기본: 지난달), 사무소 이름·연락처를 넣는다.
2. 앱이 기준 달까지 12개월을 받아 **사실 자료**를 계산한다: 이달 거래 수, 단기(최근 3개월 vs 그 전 3개월)·중장기(최근 3개월 vs 조회 기간 처음 3개월, 약 9개월 간격) 가격 변화, 거래가 많은 면적대, 이달 주요 거래, 최고가 경신 거래, 해제 수.
3. 분석 모델에게 사실 자료와 **작성 규칙**을 주고, 제목·단기 판단·중장기 판단 세 부분을 받는다.
4. 받은 문장 속 숫자를 자료와 대조한다. 맞는 숫자는 점선 밑줄, 자료에 없는 숫자는 빨간 물결 밑줄과 경고.
5. A4 한 장 문서로 보여 준다: 제목 → 모델의 판단 → 최근 6개월 표 → 눈여겨볼 거래 → 사무소 정보.
6. 인쇄 / PDF 저장(브라우저 인쇄 창).

## 하지 않는 것

- 모델이 숫자를 계산하게 하기 (숫자는 언제나 앱이 계산)
- 매수·매도 권유 문장
- 여러 동네 묶음 브리핑, 자동 발송(5번 시나리오의 몫)
- 서버 저장, 로그인
