바로 받기

키트에는 실제 키가 들어 있지 않습니다. 키 없이도 서울 강남구 예시 데이터로 먼저 볼 수 있습니다.

설치하고 만들기

처음 한 번만 준비하면 됩니다. 쓰는 컴퓨터를 고르세요.

  1. Node.js 22 설치

    nodejs.org 에서 LTS 버전을 받아 설치합니다.

    설치 파일(.msi)을 실행하고 계속 "다음"을 누릅니다. 끝나면 PowerShell 을 새로 열어 확인합니다.

    설치 파일(.pkg)을 실행합니다. 끝나면 터미널 을 새로 열어 확인합니다.

    node -v

    v22 이상이 나오면 성공입니다.

  2. AI 코딩 도구 준비

    아래 중 하나면 됩니다. 이미 쓰고 있는 것이 있으면 그것을 씁니다.

    • Claude Code 설치 안내대로 설치
    • Codex 설치 안내대로 설치
    • Cursor 같은 AI 편집기

  3. 키트 받고 압축 풀기

    위의 바로 받기 또는 아래 시나리오에서 zip 을 받습니다.

    받은 파일을 오른쪽 클릭 → 압축 풀기. 바탕화면처럼 찾기 쉬운 곳에 풉니다.

    받은 파일을 더블클릭하면 같은 자리에 폴더가 생깁니다.

  4. AI 에게 맡기기

    푼 폴더를 AI 코딩 도구에서 엽니다. 터미널에서 쓰는 도구라면 그 폴더로 이동한 뒤 실행합니다.

    cd $HOME\Desktop\realdeal-s1-flow cd ~/Desktop/realdeal-s1-flow

    그리고 이렇게 말합니다.

    이 폴더의 START_HERE.md 와 CLAUDE.md 를 읽고,
docs/BUILD_PLAN.md 대로 끝까지 만들어줘.
단계마다 확인하면서 진행해.

    보통 30분~1시간 걸립니다. 끝나면 AI 가 확인한 것과 내가 할 일을 알려 줍니다.

  5. 띄우고 쓰기

    npm run dev

    브라우저에서 http://localhost:3000 을 엽니다. 화면의 인증키 칸에 공공데이터포털 인증키를 넣으면 전국 어디든 조회됩니다.
